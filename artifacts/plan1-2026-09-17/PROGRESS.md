## 实测结果

- Python 自动测试：**34 项通过**。两条第三方弃用提示不影响通过；详见 [原始测试记录](tests.txt)。
- 前端生产构建与代码检查通过；MapLibre 地图工作线程也已打包到本地资源。
- 质量漂移：`4.187e-16`，小于 1e-10。
- 32²→64²→128² 联合收敛阶：1.9945、1.9986。Euler 时间格式仍为一阶。
- 六种 λ 下，两种自写路径算法与 NetworkX 最优成本的最大绝对误差：`1.364e-12`。
- 三个 κ 的模拟耗时约 10.2–51.6 ms；九组路线请求最大约 27.8 ms。机器信息和每项耗时见报告；首次读取/构建路网另需约半秒。
- 地图仅显示真实道路；以本机字体渲染街道名，无外部字体、图标或底图请求。

## 如何继续

原项目继续开发；本阶段完成后创建同级独立文件夹 `Flow-plan1-2026-09-17`，保存全部源代码、生产界面、数据、实验历史、报告、演示、进度和当前电脑的 Python 环境。归档不含 Git 历史及前端开发依赖；`ARCHIVE_INFO.json` 保存准确提交编号。

当前电脑运行：双击根目录 `Start Flow.command`，然后打开 http://127.0.0.1:8000 。归档和原项目同时运行时，在归档中使用 `FLOW_PORT=8001 ./start.sh`。

新电脑：Python 3.12、Node.js 22.12+，运行 `./setup.sh` 安装一次，再运行 `./start.sh`。在线安装阶段包含 DuckDB Spatial，之后常规演示可离线运行。

## 范围与后续

该结果是理想化扩散实验：无风、无建筑/地形作用；反射边界；1.4m/s 固定步速；沿路暴露使用选定时刻的冻结场，不代表真实污染预测或人体剂量。

本次用 OSM 道路自行生成轻量 PMTiles，以系统字体完成离线文字；没有下载 Protomaps 全要素城市底图，也没有缓存 OSM 公共栅格瓦片。首版目标已覆盖，视觉动画保持简单。

下一阶段可选：对流扩散、隐式方法、实测瓶颈的 C++ 优化、PeMS/CWWP 数据接入与参数校准。这些没有混入本次完成状态。

原始源代码快照和用户开工前修改分别保存在 `starting-source.tar.gz` 与 `starting-user-changes.patch`。公共 README 保持英文，原有中文 README 继续留在本机。
